\section*{Corrections to the text}
\begin{enumerate}[label=]
\item \textbf{W01} (p.~141, Section 4, paragraph after Figure 7; Lean) Replace ``A full compiler can be written and Turing-completeness could be readily proven from the model as already presented.'' by ``A full compiler can be written. Turing-completeness holds for the idealized machine with unbounded code memory initialized with a repeating blank-cell template, in which each cell encodes its symbol in the displacement of one jump and write-only handlers rewrite it. For a finite image the simulation is exact while the head stays inside the image, and the machine faults when it leaves.''. \emph{Lean:} \texttt{Universal.universal\_halts\_iff}, \texttt{Universal.never\_faults}, \texttt{Universal.bounded\_halts}, \texttt{Universal.bounded\_faults}.
\item \textbf{W02} (p.~139, Section 4, paragraph beginning 'The practical details'; listing) Replace ``First of all, no registers are used in the instructions, and only jumps and data movement instructions are used.'' by ``No Write-Execute procedure uses the stack: each executed instruction is an immediate store into an instruction field, a direct jump, or a no-operation. Registers and returns occur only in the C-calling-convention entry points, which patch the argument fields and return the result.''. \emph{Lean:} \texttt{WE.step\_eq\_effect}, \texttt{WE.effect\_congr}, \texttt{WE.store\_from\_window}.
\item \textbf{W03} (p.~139, Section 4, primitives list; Lean) Replace ``division with a 64-bit divisor, and 32-bit dividend, quotient and remainder'' by ``division of a 64-bit dividend by a 32-bit divisor, with a 32-bit remainder and the quotient modulo 2\^{}32''. \emph{Lean:} \texttt{Arith.doDivision\_spec}.
\item \textbf{W04} (p.~136, Section 3, RSA paragraph; Lean) Replace ``It also requires a 64-bit divisor divided by a 32-bit dividend with a 32-bit remainder. Although the quotient cannot overflow 32-bits of output, the remainder potentially can.'' by ``It also requires a 64-bit dividend divided by a 32-bit divisor with a 32-bit remainder. The remainder always fits in 32 bits, but the quotient overflows 32 bits unless the high half of the dividend is less than the divisor, which holds when both factors are first reduced modulo the divisor.''. \emph{Lean:} \texttt{Arith.div\_lt\_word\_iff}, \texttt{Arith.mulmodFixed\_spec}.
\item \textbf{W05} (p.~136, Section 3, RSA paragraph; Lean) Replace ``an efficient implementation which requires log2 E + count\_bits(E) modular multiplications'' by ``an efficient implementation which requires floor(log2 E) + 1 + count\_bits(E) modular multiplications for E >= 1''. \emph{Lean:} \texttt{Arith.mulCount\_log2}.
\item \textbf{W06} (p.~137, Section 3, discussion of Tables 1-2; editorial) Replace ``93+5*44'' by ``93+6*44''.
\item \textbf{W07} (p.~131, Title footnote, Mathematics Subject Classification; editorial) Replace ``62K05'' by ``94A60, 68M07''.
\item \textbf{W08} (p.~134, Section 2, fourth paragraph; editorial) Replace ``which flushes the cache 4 bytes at a time'' by ``which performs a 16-byte non-temporal store that bypasses the cache and thereby evicts the line''.
\item \textbf{W09} (p.~133, Section 2, Meltdown paragraph; editorial) Replace ``256 local 512-byte pages'' by ``256 local 4096-byte pages (the Spectre proof of concept uses a 512-byte stride)''.
\item \textbf{W10} (p.~140, Figure 5, DEFINENOT (and the identical DEFINENZ); listing) Replace ``IF Index GT 0f6h'' by ``IF Index GT 0f7h''. \emph{Lean:} \texttt{X86.w10\_original\_sizes}, \texttt{X86.w10\_corrected\_sizes}, \texttt{X86.fig5\_x64}, \texttt{X86.fig5\_corrected}.
\end{enumerate}
